# Review Change

1. Read the applicable `AGENTS.md` and inspect the diff, nearby code, and relevant tests.
2. Prioritize concrete correctness, security, data-loss, compatibility, and test-coverage risks over style preferences.
3. For every finding, provide severity, file and line reference, reasoning, and a practical remediation.
4. State clearly when no blocking issue was found and list validation that remains unverified.
