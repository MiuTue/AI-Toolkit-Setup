# Fix Bug

1. Reproduce the reported behavior or obtain concrete failure evidence.
2. Trace the smallest relevant execution path and identify the root cause; distinguish it from symptoms.
3. Add or update a focused regression test when practical.
4. Make the smallest defensible fix, then rerun the reproducer and relevant checks.
5. Report the cause, changed behavior, verification, and limitations.
