# Update Documentation

1. Identify the documentation that is authoritative for the changed behavior.
2. Update only material facts: setup, configuration, API behavior, migration, operations, or decisions.
3. Keep examples executable and align names, commands, and paths with the repository.
4. Review the final documentation against the implementation before reporting completion.
