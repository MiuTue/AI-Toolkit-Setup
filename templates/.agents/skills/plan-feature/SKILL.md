# Plan Feature

1. Read `AGENTS.md`, repository documentation, and the relevant code paths.
2. State the goal, non-goals, assumptions, and observable acceptance criteria.
3. Propose small ordered steps with affected files, dependencies, risks, and a validation command for each step.
4. Put the plan in `plans/` when the repository uses that directory; otherwise present it in the response.
5. Do not implement until the requested planning scope is complete or the user asks to proceed.
