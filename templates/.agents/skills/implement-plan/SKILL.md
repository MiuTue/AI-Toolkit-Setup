# Implement Plan

1. Read the approved plan and confirm its scope against the current working tree.
2. Implement one coherent step at a time, preserving unrelated changes.
3. Run the narrowest relevant check after each meaningful change; stop and report if a required check fails.
4. Update plan status or documentation when the repository uses them.
5. Finish with a concise change summary, validation evidence, and unresolved risks.
